# 雪山飞驰 · 滑雪模拟器

基于 Three.js 的 3D 无尽滑雪网页游戏。支持**双板滑雪**和**单板滑雪**两种装备，两者手感不同：双板直线更稳更快，单板转向更灵活。

![玩法](https://img.shields.io/badge/%E7%8E%A9%E6%B3%95-%E6%97%A0%E5%B0%BD%E6%BB%91%E9%99%8D-blue)

## 运行

```bash
npm install
npm run dev       # 开发（默认 http://localhost:5173）
npm run build     # 打包到 dist/
```

## 操作

| 按键 | 功能 |
|---|---|
| ← / → 或 A / D | 转向刻滑 |
| ↓ / S | 刹车 |
| 空格 | 跳跃 |
| Shift | 压低身体加速（tuck） |
| R | 重新开始 |
| M | 静音 |

## 玩法

- 无尽下坡雪道，越滑越快、障碍越密
- 穿过红绿糖果杖**旗门** +100 分
- 收集**雪花** +10 分
- 起跳/雪堆跳台**滞空**有额外奖励分
- 撞上树木、岩石、雪人则摔倒结束，本地保存最高分

## 技术

- Three.js + Vite，纯前端无后端
- 地形为解析函数驱动的无尽坡面（物理与网格共用同一高度函数），地形块循环复用
- 雪面材质注入自定义着色器：细密闪光颗粒 + 阴面偏蓝
- 程序化天空渐变 + 太阳光晕、远山背景、漫天飘雪、刻滑喷雪、雪板刻痕尾迹
- WebAudio 程序化音效（风声 / 刻滑 / 拾取 / 撞击），无音频文件
- 滑雪者为程序化低多边形角色，带压弯、蹲伏、跳跃抓板、摔倒翻滚姿态
