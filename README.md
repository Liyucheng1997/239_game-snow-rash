# 雪山飞驰 · 滑雪模拟器（v1.1）

基于 Three.js 的 3D 无尽滑雪网页游戏。支持**双板滑雪**和**单板滑雪**两种装备，两者手感不同：双板直线更稳更快，单板转向更灵活。

![玩法](https://img.shields.io/badge/%E7%8E%A9%E6%B3%95-%E6%97%A0%E5%B0%BD%E6%BB%91%E9%99%8D-blue)

## 运行

```bash
npm install
npm run dev       # 开发（默认 http://localhost:5173）
npm run build     # 打包到 dist/
```

## 操作

| 按键 | 功能 |
|---|---|
| ← / → 或 A / D | 转向刻滑 |
| ↓ / S | 刹车 |
| 空格 | 跳跃 |
| Shift | 压低身体加速（tuck） |
| R | 重新开始 |
| M | 静音 |

## 玩法

- 无尽下坡雪道，越滑越快、障碍越密
- 穿过红绿糖果杖**旗门** +100 分
- 收集**雪花** +10 分
- 起跳/雪堆跳台**滞空**有额外奖励分
- 撞上树木、岩石、雪人则摔倒结束，本地保存最高分

## 技术

- Three.js + Vite，纯前端无后端
- 地形为解析函数驱动的无尽坡面（物理与网格共用同一高度函数），地形块循环复用
- 雪面材质注入自定义着色器：细节法线、面向太阳的闪光颗粒、阴面偏蓝、次表面透亮感
- WebAudio 程序化音效（风声 / 刻滑 / 拾取 / 撞击），无音频文件
- 滑雪者为程序化关节角色：胶囊肢体 + 车削躯干、头盔雪镜、带侧切/翘头的扫掠雪板、固定器与雪靴、雪杖；腿部用两骨 IK 让脚踝钉在雪靴上、膝盖自然弯曲
- 动作参考真实滑雪：双板刻滑全身内倾 + 上身反向角度平衡、内侧板领先、换弯点杖、犁式刹车、tuck 收杖；单板前刃/后刃换刃（髋压脚尖 / 坐髋脚跟）、横板后刃刹车、空中 Indy 抓板；落地屈膝缓冲、摔倒翻滚
- 雪景：雪面细节法线（雪道压雪纹 + 野雪粉雪凹凸）、雪道边缘雪坎与边界杆、实例化雪松密林、环形高度场远山（按坡度混合岩石/积雪）、程序云天空、带风的多尺寸飘雪、随寿命膨胀的喷雪、带雪沿的刻痕尾迹、指数雾大气透视
